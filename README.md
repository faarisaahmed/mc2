# mc2

A static website for the Muslim Center of Greater Princeton, hosted with GitHub Pages from the `main` branch.

Content is sourced from [themuslimcenter.org](https://themuslimcenter.org).

## Structure

- `index.html` – the whole site (single page, no build step)
- `styles.css` – styling
- `.nojekyll` – tells GitHub Pages to serve files as-is

## Editing

Edit `index.html` directly. Sections are marked with comments (`<!-- EVENTS -->`, `<!-- PROGRAMS -->`, etc.). Changes pushed to `main` go live within a minute or two.
